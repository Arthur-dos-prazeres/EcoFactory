📌 Sobre o Projeto

O Gestão de Máquinas é uma aplicação web desenvolvida para realizar o controle de máquinas, produção e manutenções de uma empresa.

O sistema possui uma interface moderna, integração com uma API REST e persistência dos dados utilizando PostgreSQL.

🛠 Pré-requisitos

  • Node.js versão 18 ou superior
  • npm versão 9 ou superior
  • PostgreSQL versão 13 ou superior
  • Git instalado
  • Visual Studio Code recomendado
ℹ️ Antes de começar Certifique-se de que o Node.js e o PostgreSQL estão instalados corretamente no computador.

📥 Instalação

1. Clone o projeto 

# Clone o repositório

git clone https://github.com/seu-usuario/gestao-maquinas.git

cd gestao-maquinas

2. Instale as dependências 

npm install
✓ Instalação concluída Depois da instalação, o projeto estará pronto para ser configurado.

⚙️ Configuração

Crie um arquivo chamado .env na raiz do projeto para armazenar as configurações da aplicação.

Criar arquivo .env 

# Porta da aplicação

PORT=3000


# Configuração do PostgreSQL

DB_HOST=localhost

DB_PORT=5432

DB_NAME=gestao_maquinas

DB_USER=postgres

DB_PASSWORD=sua_senha


# Chave de autenticação

JWT_SECRET=sua_chave_secreta
⚠️ Segurança Não compartilhe o arquivo .env publicamente e não envie senhas ou chaves secretas para o GitHub.

🗄️ Banco de Dados PostgreSQL

1. Criar o banco de dados 

CREATE DATABASE gestao_maquinas;

2. Executar as tabelas

Execute o arquivo SQL responsável pela criação das tabelas do sistema. 

# Exemplo

psql -U postgres -d gestao_maquinas

# Depois execute o arquivo schema.sql

\i database/schema.sql
💡 Dica Verifique se o serviço do PostgreSQL está executando antes de iniciar a aplicação.

▶️ Execução do Projeto

Ambiente de Desenvolvimento 

# Inicie o servidor

npm run dev


# Acesse no navegador

http://localhost:3000

Ambiente de Produção 

# Gere a aplicação

npm run build


# Inicie o servidor

npm start
✓ Aplicação iniciada Se tudo estiver configurado corretamente, o sistema poderá ser acessado através do endereço configurado no servidor.

🧪 Testes

Para executar os testes automatizados do projeto: 

npm test

Testar a API

Você também pode utilizar ferramentas como Postman ou Insomnia para testar os endpoints da API REST.

⚠️ Solução de Problemas

Erro de conexão com o banco
Verifique as variáveis DB_HOST, DB_PORT, DB_NAME, DB_USER e DB_PASSWORD no arquivo .env.
Porta já está em uso
Altere a variável PORT no arquivo .env ou encerre o processo que está utilizando a porta.
Módulos não encontrados
Execute novamente: 
npm install
Banco de dados não encontrado
Verifique se o PostgreSQL está executando e se o banco gestao_maquinas foi criado.
