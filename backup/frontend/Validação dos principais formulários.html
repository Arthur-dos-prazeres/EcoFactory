🛡️ Regras de Validação Comuns

Regra Descrição Exemplo
🟠 Campos obrigatórios Devem ser preenchidos obrigatoriamente. Nome da Máquina, Produto
🔴 Formato de dados Devem seguir o formato correto. Data, E-mail
🔵 Tamanho mínimo/máximo Devem respeitar a quantidade de caracteres. Descrição: mínimo 10 caracteres
🟢 Valores numéricos Devem ser números válidos e dentro do intervalo. Quantidade > 0
🟣 Valores únicos Devem ser únicos no sistema. Código da Máquina
🔐 E-mail válido Deve seguir o padrão de e-mail. usuario@email.com
